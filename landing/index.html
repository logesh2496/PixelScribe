Free AI — No Credit Card

Getting your NVIDIA API key takes 60 seconds.

PixelScribe uses NVIDIA NIM — a free-tier vision AI — to understand what's in your images and generate descriptive names. You bring your own key, so there's no middleman and no monthly bill.

  1. 1 Go to build.nvidia.com and click Sign In (top right). Create a free account if you don't have one.
  2. 2 In the left sidebar, click API Keys (or navigate to build.nvidia.com/keys).
  3. 3 Click + Generate API Key. Give it any name (e.g. pixelscribe).
  4. 4 Copy the key starting with nvapi-... — it's only shown once, so save it somewhere safe.
  5. 5 Open PixelScribe → click the ⚙ Settings icon → paste the key in the NVIDIA API Key field → click Save Settings. Done!
